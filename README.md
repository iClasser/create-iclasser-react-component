# create-iclasser-react-component

This repository contains a utility to create React components for the iClasser project.

![Screenshot 2025-03-10 at 8 49 51 AM 1](https://github.com/user-attachments/assets/2f909d51-dcb8-4015-9749-0e327e8b2146)

## Usage

To create a new React component, use the following command:

```bash
npx create-iclasser-react-component <ComponentName>
```

Replace `<ComponentName>` with the name of the component you want to create.
